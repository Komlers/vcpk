# 使用说明

三步就能开一局，其余细节按需查阅。

## 一、快速上手（三步）

1. **选择班级**：首次使用点「导入班级名单」导入 TXT（一行一个名字）；之后可用「名单编辑器」增删改。
2. **上台选手**：点击红方 / 蓝方框随机抽取，或点「输入」手动指定。
3. **选择词库与限时**：点「开始 PK」，自动全屏开战。

还没有名单也能玩：在「上台选手」里直接输入两位选手的名字就能开打，这局属于**临时体验，不记录战绩**，随时可以再导入名单。

## 二、对战方式

红蓝双方同台答题，屏幕左右各一套选项，同时作答、互不干扰。答对得分，答错不扣分。

## 三、题型说明

- **单词题**：给出英文，选正确的中文释义（或反向）。
- **词块题**：含词块的词库会加入「词块选义」「词块配对」「词块重组」三种题型，覆盖介词搭配、动词短语、固定搭配，按时长配比混合出题。

## 四、限时与超时

每局可设 30 秒～5 分钟，时间到立即结算；题池按时长自动扩满，全程不重复出题。

在「擂台设置」中还可开启**每题超时检测**（3s / 5s / 7s），超时直接跳过、双方均不计分，防止故意拖延。

## 五、连击加分

连续答对触发连击，连击越高单次得分越多；答错则连击清零。屏幕上方会显示当前连击数。

## 六、败者守擂

每局结束后，败者成为下一局擂主（红方），系统自动抽取新的挑战者（蓝方），实现车轮战。

平局时按连击纪录判定：连击低者守擂；连击相同则更换擂主；双方全对平局则清空擂主、下次重新抽取。

## 七、错词复现

答错的单词和词块进入「错词本」，下次比赛优先重考，答对即出本；结算页可发起 30 秒错词加时赛。

若不希望跨词库保留错词，可在「擂台设置」中关闭「错词记忆」。

## 八、临时赛事

勾选「本次PK不计入战绩」后，该局不记录战绩、不统计错题、败者不守擂，适合临时练习。

## 九、名单与词库

- **名单编辑器**：班级新建 / 重命名 / 删除，名字改名 / 删除，搜索与批量添加。可从 Excel / WPS 选中名字直接粘贴，点「添加帮助」查看图文步骤。
- **词库**：内置 25 个词库，按必修 1～3、选择性必修 1～2 分册分组，支持多选混合出题；也可在「自定义词库」中导入本地 JSON 词库（点「如何制作自定义词库」查看格式，可借助 AI 按模板生成）。

## 十、安装为桌面应用

用 Edge / Chrome 打开本页时，可点左上角「安装」，把网页装成桌面应用：独立窗口运行、不受地址栏干扰，断网也能打开。

已安装、或浏览器不支持时该按钮不显示，也可用浏览器地址栏右侧的安装图标。

## 十一、本地保存

班级名单、战绩、擂主、词库与配置均保存在本机浏览器（LocalStorage），不上传任何服务器；清除浏览器数据会丢失，建议保留原始文件备份。

## 十二、快捷键

| 按键 | 功能 |
|------|------|
| `F` | 进入 / 退出全屏 |
| `Esc` | 退出全屏（右上角也有按钮） |
