# 如何添加 / 导入名单

名单仅保存在本机浏览器，不会上传。下面两种方式任选其一。

## 方法一：从 Excel / WPS 直接复制粘贴（最快，推荐）

1. 在 Excel / WPS 表格中**选中存放名字的那部分单元格**（只选名字列，不要选表头、学号等其他列）；
2. 按 `Ctrl + C` 复制；
3. 打开名单编辑器，点击「**📋 批量添加**」；
4. 在弹出的文本框中按 `Ctrl + V` 粘贴；
5. 点击「**✔ 确认添加**」即可。

> 表格中复制的多个单元格，粘贴后会自动变成一行一个名字，无需手动整理。

## 方法二：先存成 TXT，再导入

1. 新建一个记事本（.txt）文件；
2. 把名字粘贴进去，**一行一个名字**；
3. 保存文件（编码选择 UTF-8）；
4. 打开名单编辑器，点击「**📥 导入TXT**」，选择该文件。

> 主页面在**还没有任何名单**时，也会直接显示「📥 导入班级名单」按钮，方便第一次导入。

## 格式要求与自动处理

- **一行一个名字**；
- 自动**去重**，重复名字只保留一个；
- 自动跳过**空行**；
- 以 `#` 开头的行会被当作**注释**跳过；
- 名字只支持：中文、英文字母、数字，以及 `·`、`.`、`-` 等符号；
- 含其他特殊字符的行会被跳过。

## 小提示

- 添加后若发现名字有误，可在名单列表中点击「**改名**」直接修改；
- 不需要的名字点击「**删除**」即可；
- 名单支持按班级分开保存，不同班级的战绩、擂主互不影响。
