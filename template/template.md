# 自定义词库格式说明

本文件介绍如何编写可导入「词汇擂台」的自定义词库 JSON 文件。可直接参考同目录下的 `template.json` 模板。

---

## 一、文件整体结构

```json
{
  "name": "我的词库名称",
  "title": "我的词库名称",
  "words": [
    ["英文单词", "中文释义"],
    ["another word", "另一个释义"]
  ],
  "chunks": [
    ["英文词块", "中文释义", "家族类型", "配对题干", "答案", "重组片段"]
  ]
}
```

- 文件必须为 **UTF-8 编码** 的 `.json` 文件
- `words` 为必填项，`chunks` 为可选项（不需要词块题时可省略或留空数组）

---

## 二、顶层字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 词库名称，显示在词库选择界面 |
| `title` | string | 否 | 预留字段，值与 `name` 相同即可 |
| `words` | array | 是 | 单词表，每个元素为 `[英文, 中文]` 二元数组 |
| `chunks` | array | 否 | 词块表，每个元素为六元数组（见下文） |

---

## 三、words（单词表）格式

每个单词是一个 **2 元素数组**：

```
[英文单词, 中文释义]
```

示例：

```json
["abandon", "抛弃；放弃"],
["ability", "能力；才能"]
```

- 一个单词有多个释义时，用分号 `；` 分隔，如 `"开关；转换；改变"`
- 英文单词统一使用小写（专有名词除外）

---

## 四、chunks（词块表）格式

每个词块是一个 **6 元素数组**：

```
[英文词块, 中文释义, 家族类型, 配对题干, 答案, 重组片段]
```

### 各字段逐一说明

| 位置 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | 英文词块 | string | 词块原文，如 `persuade sb. of sth.` |
| 1 | 中文释义 | string | 词块的中文意思 |
| 2 | 家族类型 | string | 只能填 `prep`、`phr`、`coll` 三种之一 |
| 3 | 配对题干 | string | 配对题（c2）的题干，挖空处用 `____`（四个下划线）表示 |
| 4 | 答案 | string | 配对题要填的词，如 `of`、`on` |
| 5 | 重组片段 | array 或 null | 重组题（c3）的片段数组；不出重组题则填 `null` |

### 家族类型（字段 2）

| 类型 | 含义 | 示例 |
|------|------|------|
| `prep` | 介词搭配（核心考介词） | `be sensitive to`、`persuade sb. of sth.` |
| `phr` | 动词短语 | `switch on`、`give up`、`break out` |
| `coll` | 固定搭配 / 名词短语 | `artificial intelligence`、`weather forecast` |

家族类型用于干扰项生成：系统会优先从同家族的其他词块中取干扰项。

### 配对题干（字段 3）

- 用 `____`（四个下划线）标出需要填空的位置
- 题干可以是完整句子或短语
- 示例：
  - `"persuade sb. ____ sth."`
  - `"Sleep is critical ____ health."`

### 重组片段（字段 5）

- 用于「词块重组」题型，将词块拆成若干片段，学生按正确顺序点击还原
- 建议拆为 **3 个片段**（系统会自动补 1 个干扰片段，共 4 个选项）
- 片段拆分要合理，每个片段有独立意义
- 不需要重组题时填 `null`

示例：

```json
["a sense of security", "安全感", "coll", "a sense of ____", "security", ["a sense", "of", "security"]]
```

---

## 五、三种词块题型说明

勾选含词块的词库后，系统会自动在以下三种题型中轮换：

| 题型 | 名称 | 考查方式 |
|------|------|---------|
| c1 | 词块选义 | 给出英文词块，选择正确的中文释义 |
| c2 | 词块配对 | 给出挖空的题干，选择正确的词填入 |
| c3 | 词块重组 | 将打乱的片段按正确顺序点击还原 |

- 只有填了配对题干（字段 3）的词块才会出 c2 题
- 只有提供了重组片段（字段 5）的词块才会出 c3 题
- 不满足条件的词块只出 c1 选义题

---

## 六、注意事项

1. **编码格式**：文件必须保存为 UTF-8 编码，否则中文可能乱码
2. **JSON 语法**：确保逗号、括号、引号完整，最后一个元素后面不要留多余逗号
3. **去重**：同一词库内不要重复添加相同的单词或词块
4. **词块与单词重复**：如果某个短语同时出现在 words 和 chunks 中，系统只将其作为词块出题，不会重复出单词题
5. **勾选「只加载纯单词」**：若用户在主界面勾选了该选项，即使词库含 chunks，也只会出单词题
6. **验证格式**：编写完成后，可用 JSON 校验工具检查语法，再导入程序
7. **导入后管理**：自定义词库保存在浏览器 localStorage 中，清除浏览器数据会丢失，建议保留原始 JSON 文件备份
